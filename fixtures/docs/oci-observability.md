# OCI observability

OCI Monitoring collects metrics from every service and supports custom
metric namespaces for application telemetry. Alarms evaluate metric
queries and publish to notification topics.

OCI Logging centralizes service, audit and custom logs. The Logging
Analytics service adds query and anomaly detection across log sources.

Distributed tracing follows a request across microservices. APM agents
report spans that include duration, attributes and error status.
